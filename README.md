
# Simple Interest Calculator

A Bash-based simple interest calculator developed as part of the IBM Git and GitHub final project.

## Description

This project calculates simple interest based on three values entered by the user:

- Principal amount
- Annual rate of interest
- Time period in years

## Formula

Simple Interest = (Principal × Rate × Time) / 100

For example, if the principal is 1000, the annual interest rate is 5%, and the time period is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Getting Started

### Prerequisites

- Bash shell
- Git (optional, for cloning the repository)

### Installation

Clone the repository:

```bash
git clone https://github.com/Mbuso100/simple-interest-calculator.git
cd simple-interest-calculator
```

### Usage

Run the calculator:

```bash
bash simple-interest.sh
```

Enter the principal, annual interest rate, and time period when prompted.
