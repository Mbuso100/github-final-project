
# Simple Interest Calculator

This repository contains a Bash script that calculates simple interest.

## Description

The Simple Interest Calculator takes three inputs:

- **Principal (p):** The initial amount of money.
- **Rate (r):** The annual interest rate expressed as a percentage.
- **Time (t):** The period in years.

It calculates simple interest using the formula:

**Simple Interest = (p * r * t) / 100**

## Getting Started

### Prerequisites

- A Bash-compatible terminal
- Git (for cloning the repository)

### Installation

Clone the repository:

```bash
git clone https://github.com/Mbuso100/simple-interest-calculator.git
cd simple-interest-calculator
```

### Usage

Run the script:

```bash
bash simple-interest.sh
```

Enter the principal amount, annual interest rate, and time period when prompted.

### Example

For a principal of 1000, a rate of 5%, and a time period of 2 years:

Simple Interest = (1000 * 5 * 2) / 100 = 100
